Carga Masiva

Instrucciones

Úsalo cuando los materiales ya existen y solo necesitas cambiarles el nombre y/o asignarles un código (por ejemplo, al renombrar todo el catálogo del Inventario A). Esta carga solo modifica Nombre y Código: la descripción, y todo el historial de entradas/salidas de cada material, quedan exactamente igual.

Pasos:

  1. Descarga la plantilla del inventario que quieras editar (trae el ID, código y nombre actuales de cada material).
  2. Edita las columnas Código y Nombre con los valores nuevos. No toques la columna ID: es la que identifica a cada material para saber cuál actualizar.
  3. Sube el archivo editado.

Nota: las filas sin ID válido o sin nombre se omiten. La columna de descripción de la plantilla es solo de referencia; aunque la edites, no se guarda.

📥 Descargar Plantilla para Editar

Instrucciones

Úsalo para dar de alta materiales que todavía no existen en el sistema (por ejemplo, para llenar desde cero el Inventario B o C). Cada fila crea un material nuevo en el inventario que elijas abajo. Su archivo Excel (.xlsx) debe tener una estructura específica: la primera fila debe contener los encabezados y los datos deben comenzar en la segunda fila. Puede usar el botón "📥 Descargar Plantilla" en la página de Admin para obtener un archivo con el formato correcto.

El orden de las columnas debe ser el siguiente:

  1. Nombre: (Texto, Obligatorio)
  2. Descripción: (Texto, Opcional)
  3. Grupo (Categoría): (Texto, Obligatorio)
  4. No. Métrico: (Texto, Opcional)
  5. Origen: (Texto, Opcional)
  6. Fuente (Quién paga): (Texto, Obligatorio)
  7. Empresa Proveedora: (Texto, Obligatorio)
  8. Presentación: (Texto, Opcional)
  9. Unidad de Medida: (Texto, Opcional)
  10. Existencia Inicial Física: (Número, Obligatorio)
  11. Costo Unitario Inicial (Q): (Número, Obligatorio)
  12. Código: (Texto, Opcional)

Nota: Las filas que no contengan los datos obligatorios o tengan un formato incorrecto en las columnas numéricas serán omitidas. Si un 'Grupo', 'Fuente' o 'Proveedor' no existe en el sistema, será creado automáticamente durante la carga.
